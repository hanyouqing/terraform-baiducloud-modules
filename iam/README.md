# BaiduCloud IAM

IAM users, access keys, custom policies, groups, and attachments.

For **SAML / SSO**, create sub-users/groups here, then configure IdP in Console
using the [`../saml`](../saml/) scaffold (no SAML IdP resource in the provider yet).

## Examples

- `examples/basic` — CI user + policy
- `examples/complete` — deploy + break-glass + operators group
